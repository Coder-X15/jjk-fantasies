# Explore Jujutsu Kaisen through an app.
Yes, and I mean it. Swipe through the wonderful gallery of Jujutsu sorcerers, their sayings and episode vaults, and walk through the hall of Jujutsu Kaisen, one of the most influential anime ever made.

## Installation and Running
1. Git clone this repo: `git clone https://github.com/diyajojo/jjk-fantasies.git`
2. Run `flutter create .` in the project root. Now run this using `flutter run` and you should have it up and running 😀

## Issues
This app was ran on a Medium 35 phone emulator with Java SDK version 21; in case the app doesn't build for Android, go to `./android/settings.gradle` and change the version number specified near `com.android.application` to 8.2.1 (I had to do this possibly because the Flutter SDK version on `pubspec.yaml` or anything else that matters in determining the Java SDK version/ Gradle version must be wrong; with that one fix, despite a few warnings that may pop up, the app runs perfectly on the emulator)
